# Reference solutions

Completed versions of the exercise files, for reference and to unblock you if a
time-box runs out.

**Try the exercise first.** You learn retrieval and memory by wrestling with
them, not by reading the answer. Only open these if you're stuck or the timer is
up.

| Exercise | Solution file | Edit this instead |
|----------|---------------|-------------------|
| R1, R2 (retrieval) | `solutions/retrieve.py` | `src/retrieve.py` |
| M1, M2 (memory)    | `solutions/memory.py`  | `src/memory.py` |
| E1 (embeddings), R3 (retrieval) | `solutions/extras.py` | `src/embeddings.py`, `src/retrieve.py` |
| A1, A2, A3 (agent)  | `solutions/agent.py`  | `src/agent.py` |
| G1, G2, G3 (graph)  | `solutions/graph.py`  | `src/graph.py` |
| LS1, LS2 (LangSmith) | `solutions/langsmith_utils.py` | `src/langsmith_utils.py` |
| MCP1, MCP2 (MCP server) | `solutions/mcp_server.py` | `src/mcp_server.py` |
| C1 (cost meter) | `solutions/cost.py` | `src/cost.py` |
| C2, C3 (routing) | `solutions/models.py` | `src/models.py` |
| C4 (prompt caching) | `solutions/caching.py` | `src/caching.py` |

`src/` file — don't import from here.
